# Liste finale stabilisée du catalogue

**243 produits** : 80 de départ (photos conservées), 99 complémentaires existants (photo manquante), **64 nouveaux articles** (photo manquante). Images à produire : **163**.

« Salade verte » (complémentaire) est absorbée par « Laitue » : l'entrée reste en base pour les familles qui l'ont utilisée (identifiants et historiques intacts) mais n'est plus proposée.

**Unités** — *Unité proposée* : celle d'un nouvel article / d'une nouvelle famille. *Départ actuel* : valeur actuelle du catalogue de départ (qui ne s'applique qu'aux nouvelles familles). *Unité de votre famille* : lisible dans Réglages → Catalogue → Mes produits (« Unité : … ») ; je ne peux pas la lire en production. **Aucune unité d'une famille existante n'est modifiée.**

Aucun nouvel article n'est activé automatiquement : tous sont dans « Tous les produits », la famille choisit.
