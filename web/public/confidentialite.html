Courses — Confidentialité et suppression des données

Application « Courses — Liste familiale ». Dernière mise à jour : 12 octobre 2026. Contact : .

À quoi sert l'application

Courses est la liste de courses partagée d'une famille. Elle n'est destinée qu'aux membres d'une même famille ; elle ne contient aucune publicité, aucun traceur publicitaire et ne vend ni ne partage de données à des fins commerciales.

Données enregistrées

  • Famille et profils : nom de la famille, code famille, nom affiché, identifiant et rôle de chaque profil. Le code secret n'est jamais conservé en clair : seule une empreinte irréversible est enregistrée.
  • Adresse e-mail de récupération (administrateur principal) : sert uniquement à envoyer le code famille et les liens de récupération ou de vérification.
  • Listes de courses : articles demandés, quantités, achats, historique et statistiques de la famille ; photos d'articles ajoutées par la famille.
  • Notifications (facultatives) : l'adresse technique d'abonnement de l'appareil, rattachée au profil, pour prévenir les parents et administrateurs d'une nouvelle liste.
  • Appareil : à l'activation des notifications, le type de navigateur de l'appareil (user agent) est enregistré avec l'abonnement.
  • Journaux techniques : événements de sécurité et de fonctionnement du serveur (adresse IP de la requête, échecs de connexion), conservés temporairement, sans code secret. L'adresse IP sert aussi à limiter les tentatives abusives.

Les identifiants que l'administrateur transmet à un membre de la famille (par WhatsApp ou par copie) sont envoyés par l'administrateur lui-même : l'application n'envoie rien à WhatsApp et ne conserve pas le code secret en clair.

Aucune donnée de localisation, de contacts, de microphone ni d'appareil photo en continu n'est collectée. Une photo n'est envoyée que si vous choisissez d'en ajouter une à un article.

Prestataires techniques

  • Hébergement et base de données : Railway (serveur de l'application, base de données et stockage des photos).
  • Envoi d'e-mails (récupération du code famille, vérification de l'adresse, nouveau code secret) : Brevo, qui reçoit l'adresse du destinataire et le contenu du message.
  • Notifications : le service de notifications du téléphone (Google Firebase Cloud Messaging sur Android) transporte un message chiffré ; il ne contient pas de noms de produits.

Les échanges avec le serveur sont chiffrés (HTTPS).

Conservation et sauvegardes

Les données sont conservées tant que la famille existe. Des sauvegardes chiffrées de la base sont conservées pour la reprise après incident (7 jours, 4 semaines, 3 mois) puis supprimées automatiquement.

Supprimer vos données

  • Toute la famille : l'administrateur principal ouvre Réglages → Réinitialiser la famille. Après vérification du mot de passe et du code famille, la famille, les profils, les listes, les achats, les historiques, les photos de la famille, les abonnements aux notifications et l'adresse de récupération sont supprimés définitivement. Les sauvegardes existantes contiennent encore ces données jusqu'à leur expiration automatique (3 mois au plus).
  • Un seul compte, sans supprimer la famille : chaque personne peut supprimer son propre profil, depuis l'application (son profil → Supprimer mon compte) ou depuis la page publique de suppression de compte (sans connexion préalable : code famille, identifiant et mot de passe). Son nom, son identifiant et son code sont effacés, ses accès fermés et ses abonnements aux notifications supprimés ; dans l'historique des achats de la famille, son nom devient « Ancien profil ». La famille et les autres profils ne changent pas. Le profil principal (qui détient l'adresse de récupération) ne se supprime qu'avec toute la famille.
  • Un administrateur peut aussi supprimer le profil d'un parent ou d'un membre du personnel (Réglages → Famille et profils → Profil → Supprimer ce profil).
  • Vous ne pouvez plus vous connecter : demandez à l'administrateur de votre famille de supprimer votre profil, ou écrivez à .
  • Désinstaller l'application n'efface pas les données de la famille sur le serveur ; elle efface seulement les données locales du téléphone.

Vos droits

Vous pouvez demander l'accès, la rectification ou la suppression de vos données. Pour les exercer, utilisez les moyens ci-dessus ou écrivez à .
