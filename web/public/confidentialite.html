Mes Courses — Confidentialité et suppression des données

Application Android « Mes Courses » (app.smartcourse.courses.natif) et application web « Courses — Liste familiale », qui partagent le même serveur. Dernière mise à jour : 14 octobre 2026 (application Android « Mes Courses », création de famille vérifiée par e-mail, suppression de compte et durées de conservation). Contact : .

À quoi sert l'application

Mes Courses est la liste de courses partagée d'une famille. Elle n'est destinée qu'aux membres d'une même famille ; elle ne contient aucune publicité, aucun traceur publicitaire et ne vend ni ne partage de données à des fins commerciales.

Données enregistrées

  • Famille et profils : nom de la famille, code famille, nom affiché, identifiant et rôle de chaque profil. Le code secret n'est jamais conservé en clair : seule une empreinte irréversible est enregistrée.
  • Adresse e-mail de récupération (administrateur principal) : sert uniquement à envoyer le code famille, le code de vérification à la création de la famille et les liens de récupération ou de vérification.
  • Création de la famille depuis l'application : la demande (nom de la famille, prénom, identifiant, ville, adresse e-mail, empreinte du code d'accès et empreinte non réversible de l'adresse IP) est enregistrée pour vérifier l'adresse par un code à 6 chiffres et limiter les créations abusives. Rien n'est créé tant que le code n'est pas vérifié.
  • Listes de courses : articles demandés, quantités, achats, historique et statistiques de la famille ; photos d'articles ajoutées par la famille.
  • Notifications (facultatives) : dans l'application web, l'adresse technique d'abonnement de l'appareil, rattachée au profil, pour prévenir les parents et administrateurs d'une nouvelle liste. Dans l'application Android « Mes Courses », aucun abonnement n'est enregistré : le téléphone vérifie lui-même le serveur à intervalles réguliers (environ toutes les 15 minutes, au moment choisi par Android) ; les notifications ne sont donc pas instantanées.
  • Prix indicatifs et préférences : les prix de vos produits (propres à la famille) et vos choix d'affichage des prix (propres à chaque profil). Les favoris (modèles de liste) sont enregistrés pour la famille.
  • Prix partagés (facultatif) : si un administrateur choisit « Partager ce prix », sont envoyés : le produit du catalogue, son prix avec son unité ou son conditionnement, la date et, s'ils sont saisis, la ville et le magasin. Jamais le nom, l'e-mail, le code famille ni l'historique de courses. Une empreinte opaque de la famille, non réversible, sert seulement à limiter le nombre d'envois et à retirer ses contributions si la famille est supprimée. Les propositions affichées aux autres familles sont des médianes de plusieurs familles pour un même format ; rien n'est appliqué sans le choix d'un administrateur.
  • Appareil : dans l'application web, à l'activation des notifications, le type de navigateur de l'appareil (user agent) est enregistré avec l'abonnement.
  • Journaux techniques : événements de sécurité et de fonctionnement du serveur (adresse IP de la requête, échecs de connexion), conservés selon les règles de l'hébergeur (Railway), sans code secret. L'adresse IP sert aussi à limiter les tentatives abusives.

Les identifiants que l'administrateur transmet à un membre de la famille (par WhatsApp ou par copie) sont envoyés par l'administrateur lui-même : l'application n'envoie rien à WhatsApp et ne conserve pas le code secret en clair.

Aucune donnée de localisation, de contacts, de microphone ni d'appareil photo en continu n'est collectée. Une photo n'est envoyée que si vous choisissez d'en ajouter une à un article.

Prestataires techniques

  • Hébergement et base de données : Railway (serveur de l'application, base de données et stockage des photos).
  • Envoi d'e-mails (récupération du code famille, vérification de l'adresse, nouveau code secret) : Brevo, qui reçoit l'adresse du destinataire et le contenu du message.
  • Notifications de l'application web : le service de notifications du navigateur (Google Firebase Cloud Messaging sur Android) transporte un message chiffré ; il ne contient pas de noms de produits. L'application Android « Mes Courses » n'utilise aucun service de notification tiers, aucune publicité ni aucun outil de mesure d'audience.

Les échanges avec le serveur sont chiffrés (HTTPS).

Conservation

  • Famille, profils, listes, historique, favoris, prix : conservés tant que la famille existe, jusqu'à leur suppression (voir plus bas).
  • Demandes de création de famille (adresse e-mail, nom de la famille, prénom, identifiant, ville, empreinte de l'adresse IP) et journal des e-mails de code de vérification : le serveur efface les éléments de plus de 30 jours à son démarrage puis toutes les 6 heures, et immédiatement si le compte qui a créé la famille ou la famille est supprimé. Rien n'est créé tant que le code n'est pas vérifié ; un code expire au bout de 30 minutes.
  • Liens envoyés par e-mail : vérification de l'adresse valable 48 heures, nouveau code d'accès 60 minutes ; seule une empreinte est conservée, effacée avec le compte.
  • Sessions : une connexion reste ouverte 90 jours sans utilisation au plus ; elle est fermée immédiatement à la déconnexion, au changement de code d'accès ou à la suppression du compte.
  • Journal de sécurité (actions sur les profils, sans nom ni adresse) : conservé avec la famille et effacé avec elle ; après la suppression d'une famille, il ne reste qu'une trace anonyme (empreinte non réversible du code famille et nombre d'éléments supprimés).
  • Journaux techniques du serveur (adresse IP des requêtes) : conservés par l'hébergeur (Railway) selon ses propres règles ; nous n'en fixons pas la durée.
  • Sauvegardes : des sauvegardes de la base peuvent exister pour la reprise après incident ; elles peuvent encore contenir des données supprimées jusqu'à leur propre suppression. Nous n'annonçons pas de durée tant qu'elle n'est pas vérifiée.

Supprimer vos données

  • Mon compte seulement (tous les rôles) : dans l'application, Compte (icône en haut à droite) → Supprimer mon compte, avec votre code d'accès ; ou sur la page publique de suppression de compte (sans connexion préalable : code famille, identifiant et code d'accès). Sont effacés immédiatement : votre nom, votre identifiant, votre code d'accès, votre ville, vos réglages, votre adresse e-mail le cas échéant, les liens et le journal des e-mails qui vous concernent, et vos abonnements aux notifications. Vos accès sont fermés sur tous vos téléphones et la reconnexion est refusée. Restent, car ils appartiennent à la famille, sans votre nom ni votre identifiant : les articles que vous avez demandés et leurs quantités, vos achats (article, quantité, date et heure, prix indicatif), les modifications de la liste que vous avez faites (journal de la liste) et vos validations de sélection ; partout, votre nom est remplacé par « Ancien profil ». Le profil supprimé ne garde qu'un identifiant technique interne, sans lien avec votre nom ou votre identifiant, auquel ces éléments et le journal de sécurité restent rattachés. La famille et les autres membres ne changent pas. Désactiver un profil n'est pas le supprimer.
  • Administrateur principal : son compte tient la famille (adresse de récupération, suppression de la famille). Pour supprimer seulement son compte, il confie d'abord ce rôle à un autre administrateur (Compte → Supprimer mon compte → Transférer le rôle) ; son adresse de récupération est alors effacée immédiatement (elle n'est pas transmise au nouvel administrateur principal), ainsi que les liens qui lui avaient été envoyés et pas encore utilisés. Le nouvel administrateur principal enregistre la sienne dans Réglages → Récupération et la confirme par le lien reçu (valable 48 heures). Tant qu'elle n'est pas confirmée, la famille n'a pas d'adresse de récupération : pas de rappel du code famille ni de nouveau code d'accès par e-mail, et la suppression de toute la famille est impossible.
  • Toute la famille (administrateur principal uniquement) : Compte → Supprimer mon compte → Supprimer toute la famille, ou Réglages → Supprimer toute la famille. Après le code d'accès, le code famille et une confirmation, sont supprimés définitivement : la famille, tous les profils, les listes, les achats, l'historique, les favoris, les prix de la famille et ceux qu'elle avait partagés, les photos de la famille, les abonnements aux notifications, l'adresse de récupération et la demande de création de la famille. Plus aucun membre ne peut se connecter.
  • Une liste clôturée : un administrateur peut la supprimer depuis l'historique (Supprimer la liste) ; la liste et ses achats sont supprimés définitivement et les statistiques recalculées.
  • Un administrateur peut aussi supprimer le profil d'un parent ou d'un membre du personnel (Réglages → Profils → ⋮ → Supprimer le profil) : mêmes effets que « Supprimer mon compte ».
  • Vous ne pouvez plus vous connecter : demandez à l'administrateur de votre famille de supprimer votre profil, ou écrivez à .
  • Dans tous les cas, les sauvegardes déjà faites, s'il en existe, peuvent encore contenir les données supprimées jusqu'à leur propre suppression.
  • Désinstaller l'application n'efface pas les données de la famille sur le serveur ; elle efface seulement les données du téléphone. Après la suppression d'un compte, l'application efface aussi les données de ce profil gardées sur le téléphone.

Vos droits

Vous pouvez demander l'accès, la rectification ou la suppression de vos données. Pour les exercer, utilisez les moyens ci-dessus ou écrivez à .
